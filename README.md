🏠 Mera Basera

Find a room. Find your place. Start your college journey.

Mera Basera is a student-focused room & PG finder built for college students in India.

Every year, thousands of students get admission into college and face one common problem:

«"Where do I actually live?"»

Mera Basera makes finding accommodation easier. Search your college name, explore available rooms and PGs, compare rent, distance, amenities and real photos — all from one place.

🎯 The Problem

Moving to a new city for college is exciting — but finding a decent room or PG isn't always easy.

Students often have to:

- 🚗 Travel to the city just to search for rooms
- 💸 Spend money while visiting multiple properties
- ⏳ Waste valuable time during admission season
- 📸 Depend on limited or unclear property information
- 🤔 Struggle to know which listings can be trusted
- 🏠 Search separately for roommates

💡 Mera Basera brings the process together in one platform.

---

🔍 What Mera Basera Does

Search for your college name and discover rooms and PGs around your campus.

Students can view:

- 💰 Rent
- 📍 Distance from campus
- 🛋️ Amenities
- 📸 Real property photos
- ✅ Verified listings
- ⭐ Premium listings
- 🏠 Roommate opportunities

«Less searching. Less travelling. More time for college.»

---

✨ Features

🔍 Search by College

Type your college name and explore available rooms and PGs around it.

✅ Verified Listings

Property listings can be manually verified to provide an additional layer of trust.

📸 Real Photos

Owners can upload actual photos of their rooms and properties.

🏠 Roommate Finder

Students can list themselves and find potential roommates who may want to share accommodation and split rent.

🔑 Owner Registration

A dedicated registration flow allows PG and room owners to list their properties in just a few minutes.

💬 Feedback System

Students can share their experience through testimonials. Feedback is moderated before being published.

🔐 Student & Owner Accounts

Students and property owners can create accounts and access features through their personal dashboard.

❤️ Save Favorites

Students can save interesting listings and check them later from their dashboard.

🚀 Getting Started

Prerequisites

Make sure you have Node.js and npm installed.

1. Clone the repository

git clone https://github.com/h4ckerstark1/mera-basera.git
cd mera-basera

2. Install dependencies

npm install

3. Start the development server

npm run dev

4. Build for production

npm run build
